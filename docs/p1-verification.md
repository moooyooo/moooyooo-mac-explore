## 初期の性能記録

初回のRelease試作で計測した参考値。各構成1回の測定であり、p95の合格判定ではない。
初期表示時間は実行ファイルの`main`開始から、最初のフォルダ一覧を読み込んで
テーブルへ反映するまで。OSの起動要求からプロセス開始までの時間や描画完了は含まない。

| 条件 | 初期一覧の反映 | physical footprint |
| --- | --- | --- |
| 1親・1子、1,000項目 | 約0.417秒 | 約36.5 MiB |
| 2親・合計6子、各1,000項目 | 最初の子で約0.471秒 | 約81.6 MiB |

メモリは最初の読込通知から3秒後、`TASK_VM_INFO.phys_footprint`で測定した。
6子画面のプロセスの待機時CPUは60.02秒のCPU時間差で0.0%だった。
これは`ps`が報告するCPU時間の分解能で増加を検出しなかったという意味である。
ディレクトリ変更監視やプレビューは未実装のため、追加後に再測定する。
今回の最終Release `.app`は`du -sh`で532 KiBだった（デバッグシンボルを除く）。

再現例（同じ生成先が存在する場合は別の名前を指定）:

```sh
python3 scripts/create-fixture.py .local/fixtures/1000 --count 1000
open -n "build/Moooyooo Mac Explore.app" --args \
  --folder "$PWD/.local/fixtures/1000" \
  --diagnostics-file "$PWD/.local/metrics-single.json"
open -n "build/Moooyooo Mac Explore.app" --args --demo \
  --folder "$PWD/.local/fixtures/1000" \
  --diagnostics-file "$PWD/.local/metrics-multi.json"
```

診断JSONのPIDを確認し、そのプロセスを操作しない状態で
`python3 scripts/measure-idle.py PID --seconds 60 --output .local/idle.json`を実行する。
診断JSONにはフォルダのパスや項目名を含めない。`.local/`はGit管理対象外。
