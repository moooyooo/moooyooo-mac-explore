# UX・ショートカット仕様

状態: 設計案。優先する操作体系はWindows Explorer。
Windowsのキー動作は[Microsoft公式の一覧](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows)を参照した。
以下のMDI・プロジェクト用キーとMac上での割当は、このアプリの設計である。

0.6.0開発版では閲覧・MDI・プロジェクトに加え、基本ファイル操作、コンテキスト
メニュー、ファイルURLのDnD、キーのプリセット切替、表示メニューと列設定を実装した。
表全体は目標仕様を含み、実画面・Finderの検証も残る。
実装済みのプロジェクト操作は[操作手順](projects.md)を参照。

## 1. 画面構成

```text
macOSメニューバー
  App / ファイル / 編集 / 表示 / 移動 / プロジェクト / ウィンドウ / ヘルプ

┌ MDI親ウィンドウ：開発プロジェクト ─────────────────────────┐
│ プロジェクト切替  保存  Explorer追加  整列                   │
│ ┌ Explorer：ソース ─────────────── [最小化][最大化][閉じる]┐ │
│ │ 戻る 進む 上へ  パンくず／パス          フォルダ内検索 │ │
│ │ ┌ ナビゲーション ┐ ┌ 名前 / 更新日時 / 種類 / サイズ ┐│ │
│ │ │ お気に入り     │ │ ファイル・フォルダ一覧           ││ │
│ │ │ ホーム         │ │                                ││ │
│ │ │ ボリューム     │ │                                ││ │
│ │ │ フォルダツリー │ │                                ││ │
│ │ └────────────────┘ └────────────────────────────────┘│ │
│ │ 件数・選択状態・読み込み状態                           │ │
│ └────────────────────────────────────────────────────────┘ │
│       ┌ Explorer：出力先（独立して移動・サイズ変更） ────┐ │
│       │ …                                                │ │
│       └──────────────────────────────────────────────────┘ │
│ 最小化した子画面の一覧                                      │
└────────────────────────────────────────────────────────────┘
```

macOSのネイティブメニューを使い、前面の親ウィンドウとアクティブな子画面に追従する。
各子は自分のアドレス・履歴・ツリー・一覧を持つ。選択した子はタイトルと枠、
アクセシビリティの状態で区別する。複数画面でも現在の操作対象が曖昧にならないようにする。

一覧は初期状態を詳細表示とする。フォルダを先頭、名前を自然順で並べ、列ヘッダーで変更できる。
ダブルクリック／Enterでフォルダへ移動し、ファイルなら既定アプリで開く。
子の最小化は親内部の一覧へ収納し、最大化は親の作業領域だけを使う。
親のフルスクリーンと子の最大化は別の操作とする。

## 2. メニュー

| メニュー | 主な項目 |
| --- | --- |
| App | このアプリについて、設定、非表示、終了 |
| ファイル | 新しいExplorer、新しいMDIウィンドウ、別プロセスで起動、開く、フォルダ作成、名前変更、ゴミ箱へ移動、子を閉じる、親を閉じる |
| 編集 | 元に戻す、切り取り、コピー、貼り付け、すべて選択、パスをコピー |
| 表示 | 詳細表示、並べ替え、列の設定、隠し項目、ナビゲーション表示、更新 |
| 移動 | 戻る、進む、上へ、ホーム、パスへ移動、お気に入り |
| プロジェクト | 新規、開く、現在の親で切り替え、別プロセスで開く、保存、別名保存、最近使った項目 |
| ウィンドウ | 次／前の子、子の最大化／復元、子の最小化、縦整列、横整列、重ねて表示、子の移動／サイズ変更、親と子の一覧 |
| ヘルプ | 操作ガイド、ショートカット一覧、診断情報 |

利用できない項目は無効表示とし、対象のない状態で別画面の操作を実行しない。
コンテキストメニューは選択項目と空白領域で内容を変える。診断情報はパスを伏せた表示を既定とする。

「表示 → 並べ替え」で列と昇順／降順を選び、「列の設定」で4列の順序と幅を変更する。
初期版は詳細表示のみで、列の非表示は行わない。隠し項目・ナビゲーション表示は子ごとに保存する。
列設定で入力が不正な間は理由を表示し、同じシートで修正してから適用できる。

## 3. キーボード

既定は「Explorer」プリセット。Control系と表のCommand系代替を受け付ける。
MacプリセットではControl系のアプリ独自割当を解除し、Command系を中心にする。
共通の子画面切替（Control+Tab / Control+Shift+Tab）は維持する。
アプリ名メニューの「キー操作」から即座に切り替えられる。別プロセスは前面に戻る際に
保存済み設定を読み込む。起動引数`--shortcuts mac|explorer`がある場合はそれを優先する。
全操作はメニューからも使え、メニュー／ヘルプには現在のプリセットを反映する。

表の`Alt`相当はMacの`Option`。`Delete→`は前方削除キー、`Backspace`は
Mac内蔵キーボードの`delete（⌫）`を指す。FキーはOS設定によってFn併用が必要になる。

| 操作 | Explorerプリセット | Command系代替 | 範囲 |
| --- | --- | --- | --- |
| 新しいExplorer | Ctrl+N | Cmd+N | 現在の親 |
| 新しいMDI親ウィンドウ | Ctrl+Option+N | Cmd+Option+N | 現在のプロセス |
| 別プロセスで起動 | メニュー | メニュー | 新しいプロセス |
| 子画面を閉じる | Ctrl+W | Cmd+W | アクティブな子 |
| 親ウィンドウを閉じる | Ctrl+Shift+W | Cmd+Shift+W | 現在の親 |
| 次／前の子画面 | Ctrl+Tab / Ctrl+Shift+Tab | 共通 | 現在の親 |
| 戻る／進む | Option+← / Option+→ | Cmd+[ / Cmd+] | 子の履歴 |
| 戻る | Backspace | 同左 | ファイル一覧・ツリー |
| 上の階層 | Option+↑ | Cmd+↑ | 子のフォルダ |
| パスへフォーカス | Ctrl+L / Option+D | Cmd+L | 子のアドレス欄 |
| 更新 | F5 | Cmd+R | 子の一覧 |
| 開く | Enter | 同左 | 選択項目 |
| 名前変更 | F2 | メニュー | 選択項目 |
| フォルダ作成 | Ctrl+Shift+N | Cmd+Shift+N | 子のフォルダ |
| コピー／切り取り／貼り付け | Ctrl+C / Ctrl+X / Ctrl+V | Cmd+C / Cmd+X / Cmd+V | フォーカスに従う |
| すべて選択 | Ctrl+A | Cmd+A | フォーカスに従う |
| ゴミ箱へ移動 | Delete→（内蔵ならFn+⌫） | Cmd+⌫ | 選択項目 |
| 元に戻す | Ctrl+Z | Cmd+Z | テキストまたは対応する操作履歴 |
| フォルダ内検索へ | Ctrl+F / F3 | Cmd+F | 子の名前フィルター |
| フォーカス領域の巡回 | F6 / Shift+F6 | Tab / Shift+Tab | 子内のアドレス・検索・ツリー・一覧 |
| コンテキストメニュー | Shift+F10 | メニュー／副ボタンクリック | 選択対象 |
| プロジェクトを開く | Ctrl+O | Cmd+O | 新しい親 |
| プロジェクトを保存 | Ctrl+S | Cmd+S | 現在の親 |
| プロジェクトを別名保存 | Ctrl+Shift+S | Cmd+Shift+S | 現在の親 |
| 終了 | メニュー | Cmd+Q | 現在のプロセス |

Ctrl+Nを子の追加に、Ctrl+Tabを子の巡回に割り当てる点はMDIへの適応である。
子をすべて閉じても親は空のワークスペースとして残す。終了や親を閉じる操作で、
進行中のファイル操作があれば待つ／中止／閉じるのキャンセルを明示する。

### 入力とOSとの衝突

- テキスト入力欄ではBackspace・Delete・Enter・矢印・Undoは文字編集／変換に渡す。
- IMEの未確定文字列がある間はアプリの操作キーを抑止し、確定・取消を優先する。
- ExplorerプリセットのCtrl+A/C/X/V/Zは、入力欄では文字編集を対象とする。
- Ctrl+Lなどの移動キーは未変換状態なら使える。Option+矢印は入力欄では文字移動を優先する。
- Ctrl+クリックはmacOSのコンテキストメニュー動作を維持する。複数選択はCmd+クリック、範囲はShift+クリック。
- Cmd+Tab、Mission Control、入力ソース切替、VoiceOverのキーをグローバルに奪わない。
- VoiceOver起動中はControl+OptionとCaps Lock修飾をコマンド処理・子画面移動へ渡さない。
- WindowsキーによるOS全体の起動操作やAlt文字メニューは初期版で再現しない。
- Shift+Deleteの完全削除は未提供。通常のゴミ箱操作へ暗黙に読み替えない。

ファイルのUndoメニューには対象操作と項目数を表示する。置き換えや不完全なUndo情報で
利用できない場合は理由を表示し、ツールチップで確認先を案内する。テキスト入力中は
その入力欄のUndoへ切り替える。

## 4. ドラッグ＆ドロップ

同一ボリューム内は移動、異なるボリュームへはコピーを既定とし、ドロップ前に操作を表示する。
Optionはコピー、Shiftは移動の明示指定とする。WindowsのCtrl+ドラッグはアプリ内での
衝突をP4で検証してから追加判断する。Finderとの間はmacOSのドラッグ操作と整合させる。
権限・同一フォルダ・子孫フォルダへの移動など、実行できない操作はドロップ前に示す。

## 5. プロジェクトの状態と切り替え

親のタイトルにプロジェクト名と未保存マークを表示する。読み取り専用なら
「プロジェクト設定：読み取り専用」と表示し、実ファイルの権限との違いを明確にする。
保存済みプロジェクトへ移動する際は「別の親で開く」と「この親で切り替え」を選び分ける。
「別プロセスで開く」もプロジェクトメニューから選べる。

子画面を復元できない場合は、その場所に理由・再試行・参照先の選び直しを表示する。
他の子画面は引き続き使える。保存失敗時は未保存状態を維持する。

## 6. 操作性の検証

P1でタイトルバーのキーボード移動・サイズ変更、子の巡回、最大化からの復元を試す。
P2以降でJIS/US配列、IME、外付けWindows配列、内蔵キーボード、VoiceOverを確認する。
ウィンドウサイズと画面スケールを変え、重要な操作が隠れないことをP5で確認する。
