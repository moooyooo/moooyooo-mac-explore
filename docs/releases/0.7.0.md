# 0.7.0 development preview

Maintainer: **moooyooo**. No notarized public binary has been released.

## Changes

- Pin and bundle Sparkle 2.10.0 with its complete upstream license notices.
- Add English/Japanese update menus: manual check, opt-in daily check,
  automatic download/install on quit, and install/restart.
- Require a signed appcast and Ed25519-signed archives from the moooyooo repository.
- Defer updates while other processes or file operations are active.
- Preserve workspaces across an update without overwriting project files.
- Add a durable crash barrier with recovery after a newer build or an OS reboot.
- Sign nested helpers, validate packaged update settings, and prepare signed feeds
  from Developer ID signed, notarized release archives.
- Test real Sparkle replacement using disposable hosts/keys and reject tampered feeds/ZIPs.

## Adoption and limits

Install the first updater-enabled version manually. The current signed feed is
empty; subsequent releases will appear only after reviewed binaries are published.
Apple Developer Program enrollment, Developer ID setup, notarization and a fresh-Mac
distribution test remain open. The maintainer chose to complete development testing first.
Existing manual UI, external-volume, VoiceOver and minimum-OS qualification gates remain.
See [update behavior](../updates.md), [backlog](../backlog.md) and [release preparation](../releasing.md).

Project schema version 1 and user file contents are unchanged.
