# 0.5.0 development preview — release notes draft

Prepared locally on 2026-09-27; not published. MIT license, maintained by moooyooo.
Apple Silicon / macOS 14 deployment target. Runtime verification so far uses
macOS 26.5, Apple M2 Max, 64 GiB RAM and Swift 6.3.2.

## Features

- Native AppKit Explorer panes inside multiple MDI windows and independent processes.
- Folder trees, details lists, sorting, filtering, favorites, navigation and shared monitoring.
- Saved projects, process ownership, outside-change detection and atomic saves.
- Folder creation, rename, copy/cut/paste, move, Trash, conflict choices and supported Undo.
- English/Japanese menus, dialogs and labels.

## New since 0.4.0

- Interrupted sessions recover selection, scroll anchors and back/forward history.
  Back/forward navigation also remembers recently visited folders' selection and position.
- Explorer and Mac keyboard presets, immediate menu selection and per-process overrides.
  VoiceOver modifier combinations pass through while VoiceOver is running.
- Undo menus identify the operation/count and explain unavailable groups.
- File commands wait for a newly loaded directory's sorted rows.
- Watcher registration follows its owning task; operation/Cut locks are released
  explicitly even when independent process launches overlap file operations.
- Separate APFS volume, real capacity-exhaustion and Release UI performance tests.
  [Measurements and test scope](../p5-verification.md) are recorded.

## Compatibility and limitations

Project schema version 1 is unchanged. Private recovery records add optional
browser state; older records without it remain readable. Project files still
contain paths/bookmarks and should be reviewed before sharing.

Undo is limited to supported operation groups in the current process until quit.
Replacement, external edits and other processes have limits described under
[file operations](../file-operations.md). Interrupted file operations are not
automatically resumed.

Finder drag sequences, physical removable/network drives, disconnection, real
keyboard/IME interaction, VoiceOver reading, display scaling and macOS 14 remain
unqualified. Existing screenshots show the 0.3.0 browsing UI with synthetic data.
There is no Intel/universal qualification or hosted CI result yet.
