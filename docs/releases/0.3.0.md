# 0.3.0 development preview — release notes draft

**Prepared 2026-09-26. Not published or tagged.** This is a browsing and project
management preview. No signed, notarized download is available.

## Included

- Native AppKit MDI workspaces with movable/resizable Explorer panes, tiling,
  cascading, and multiple parent windows.
- Independent application processes and project-based workspace switching.
- Folder trees, breadcrumbs, details lists, navigation history, filtering,
  sorting, hidden files, favorites and filesystem refresh.
- Project persistence with editing ownership, outside-change detection, atomic
  saves and recovery of interrupted workspace configurations.
- English and Japanese UI, system-language fallback, language selection for the
  next launch, and `--language en|ja|system` overrides.
- MIT licensing, build/validation scripts and [screenshots in both languages](../screenshots.md).

## Build and try

The deployment target is macOS 14 or later. Local validation used **macOS 26.5,
Apple M2 Max, Swift 6.3.2 and Command Line Tools**. macOS 14 and Intel remain
unqualified. A build contains the host architecture.

From the source checkout:

```sh
python3 scripts/check-localizations.py
scripts/build-app.sh release
scripts/test.sh --integration
python3 scripts/verify-app.py
open "build/Moooyooo Mac Explore.app"
```

Use the app-name menu's **Language / 言語** submenu to change language for the next
launch. The [synthetic demo](../../examples/README.md) opens two panes without using
personal files. See the [README](../../README.md) for shortcuts and project usage.

## Verification and distribution

The local suite has 38 tests covering project integrity, failure injection, real
process ownership/recovery, AppKit restoration and relocated English/Japanese
bundles. Both documentation images have been visually reviewed. See the
[verification record](../p6-verification.md) for exact scope and results.

GitHub CI is configured for macOS 14 and 26. Once run, it retains the verified
development ZIP, SHA-256 and build metadata for 14 days. No hosted result exists
yet. Development archives are ad-hoc signed and are not notarized releases.

Before publishing, record the actual source commit/tag, workflow results, artifact
name, architecture and SHA-256 here or in the GitHub release description.
The [release procedure](../releasing.md) covers packaging and first-download checks.

## Compatibility and known limitations

- Project JSON remains **schema version 1**. Language changes preserve project
  names, file names, saved paths and bookmark data.
- File creation, rename, copy, move, trash, drag-and-drop and file-operation Undo
  are not implemented. Edit-menu clipboard commands currently apply to text fields.
- Recovery restores workspace configurations; selections, scroll positions and
  navigation history are not yet restored.
- Manual keyboard/mouse, IME, VoiceOver, native dialog and display-scale checks,
  full UI performance qualification and minimum-OS validation remain incomplete.
- Developer ID signing, notarization and first-download testing are outstanding.
  The full P4/P5/P6 acceptance criteria still apply to a general-use release.
