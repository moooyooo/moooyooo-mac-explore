# 0.6.0 development preview — release notes draft

Prepared on 2026-09-27. MIT, maintained by moooyooo.
Development source: [moooyooo/moooyooo-mac-explore](https://github.com/moooyooo/moooyooo-mac-explore).
This draft is not a tagged binary release.
Apple Silicon / macOS 14 deployment target. Local verification uses macOS 26.5.

## Changes

- View-menu sorting, ascending/descending order, column order/width editing and reset,
  navigation visibility and hidden items; Go → Home.
- Column validation explains invalid widths or duplicate positions without closing
  the sheet. Cancel preserves the previous configuration.
- Per-pane error recovery: Retry, Open Folder and Return to Current Folder.
  Failed directory reads hide stale rows and disable file actions on those rows.
- Custom backgrounds, dividers and pane borders update when appearance changes.
- Folder selection keeps the Explorer that opened the dialog as its target.
- English/Japanese light/dark [workspace captures](../screenshots.md).
- Compatibility and native action tests, plus a guard against successful exit codes
  from incomplete Swift Testing runs.

## Compatibility

Project schema remains version 1. The new `settings.showNavigation` preference is
optional; existing projects default to showing the navigation tree. Older apps
ignore this field and may remove it when saving.
Selection, viewport and history remain private session data.

## Qualification and limits

[P5 verification](../p5-verification.md) records the local test results and prior
0.5.0 performance measurements. The latter have not been remeasured in full for 0.6.0.
Native control actions and exported AppKit views do not qualify physical keyboard,
mouse, IME, VoiceOver or Finder drag interactions.

Disconnected volumes and deleted paths currently share the missing-folder message.
Physical removable/network drives, disconnection, large-file cancellation, display
scaling, macOS 14 and hosted CI remain unqualified. Undo and replacement limits
remain as described in [file operations](../file-operations.md).

See [current TODOs and maintainer actions](../backlog.md).
The development package is ad-hoc signed. Developer ID, notarization and a fresh
download/install test are still required for general distribution.
Release tagging and binary upload have not been performed.
