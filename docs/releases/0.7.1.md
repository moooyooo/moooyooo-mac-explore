# 0.7.1 development preview

Maintainer: **moooyooo**. No notarized public binary has been released.

## Changes

- Add an original blue-window and gold-folder application icon. The PNG master,
  ICNS, generation prompt and native size-conversion script are included in the repository.
  See [icon provenance](../app-icon.md).
- Preserve the selected sidebar folder and visible scroll anchor when children change.
  If the selected folder disappears, clear its selection without navigating to a neighboring item.
- Skip rebuilding unchanged tree rows. Preserve MDI view instances and change their
  stacking order only when the order actually changes.
- Add AppKit regression tests and a disposable debug app that sends mouse events
  to its own Home/Downloads rows in single and multiple pane layouts.

## Verification and scope

The regression test reproduced a lost descendant selection when an earlier folder
was inserted into an expanded tree. It passes with the fix.
Selection, scrolling, focus, settled layouts and native mouse-event checks use
synthetic data; the Home selection test also reads the current user's home directory.

Local verification on 2026-09-28 (macOS 26.5, Apple M2 Max, Swift 6.3.2):

- 102 test definitions, 96 active integration tests passed in 10.459 seconds;
  the 6 optional volume/performance tests were not repeated locally for this change.
- All 16 native mouse-event cases passed: Home/Downloads, collapsed/expanded,
  760/1180-point parent width, one/two Explorer panes, including inactive-pane activation.
- All 248 localization keys, 6 Python checks, Release resources and nested signatures passed.
- The icon was reviewed at full size and 64 px. All 10 icon representations are present.
- The 147 intended repository files contain no matches for the checked private-home,
  private-key or token patterns, and no broken local Markdown links.
  This is a scoped pattern scan, not a complete security guarantee.

```sh
scripts/build-app.sh release
scripts/test.sh --integration
python3 scripts/test-sidebar.py
python3 scripts/verify-app.py
```

The sidebar probe requires a macOS GUI session. It uses an isolated support directory,
never operates on another app's windows, and saves path-free results to
`.local/sidebar-verification.json`. Its launch flag and implementation are compiled
out of Release. It does not require Accessibility or Screen Recording permission.

Computer Use still reports missing permissions on the development Mac.
The complete visual shaking reported by the user has not been reproduced; the
related selection defect and redundant redraw paths were fixed. Confirmation in
the user's original workspace remains tracked as [I-07](../backlog.md).

Automatic-update behavior and project schema version 1 are unchanged.
The signed update feed remains empty; this development build is installed manually.
Developer ID, notarization and the existing release gates remain open.
