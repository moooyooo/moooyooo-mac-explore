# プロジェクトの操作と形式

対象: 0.5.0 / プロジェクト形式バージョン1

## 保存・切り替え

1. Explorerを追加し、フォルダと配置を整える。
2. ツールバーの保存、またはCmd/Ctrl+Sで`.mexplore`へ保存する。
3. Cmd/Ctrl+Oは別の親ウィンドウに開く。同じプロセス内ですでに開いていれば、その親へ移動する。
4. 「プロジェクト → このウィンドウを切り替える」で現在の構成を置き換える。
5. Cmd/Ctrl+Shift+Sは別のプロジェクトとして保存し、新しいプロジェクトIDを付ける。

未保存の構成がある場合、親を閉じる・切り替える・アプリを終了する際に、
保存／破棄／キャンセルを選べる。保存に失敗すると未保存状態を維持する。
保存中に配置などを変更した場合、その変更は未保存のまま残る。
最初に表示されるホームだけの構成は、変更するまで確認なしで閉じられる。

## 別プロセスと保存権

「保存済みプロジェクトを別プロセスで開く」は、ディスク上の保存済み構成を開く。
未保存変更は先に保存する。通常の「ファイル → 別プロセスで起動」は新しい構成で始める。

同じプロジェクトは最初の保持者だけが保存でき、後から開いた側には
「構成は読み取り専用」と表示する。後者も閲覧や配置変更はでき、別名保存できる。
「最新を読み直して編集権を再取得」は、未保存変更の扱いを確認してから最新ファイルを読み直す。
保持者が正常終了・異常終了するとOSがロックを解放する。

ロックはApplication Supportの専用ファイルへ付け、本体の原子的置換をまたいで維持する。
シンボリックリンク・大小文字の別表記を正規化する。ハードリンクや書込み不可のファイルは
読み取り専用で開く。別名保存には、書込み可能な独立した保存先を使う。
ロックファイルの存在は使用中を意味しないため、手動削除しない。

保存前と置換直前に、現在の内容と読込時の内容を比較する。外部変更・削除を検出した場合は
上書きを停止する。非協調的な別アプリによる最後の比較から置換までの競合は完全には防げない。
初期の検証対象はローカルAPFS。ネットワーク・クラウド同期領域での共同編集は未対応。

## 欠落したフォルダ・復旧

フォルダ参照にはURLと補助bookmarkを保存する。移動された場所を解決できれば追従する。
bookmarkの解決ではUI表示やボリュームの自動マウントを要求しない。
未接続・削除済み・権限不足でも他の子は利用できる。
接続後はF5、または「ファイル → フォルダを開く」で参照先を選び直す。

構成・選択・スクロールの変更が止まってから約1秒で、プロセスごとの復旧情報を保存する。
保存先は`~/Library/Application Support/io.github.moooyooo.MacExplore/Sessions/`。
プロジェクト本体には自動保存しない。正常終了したプロセスの復旧ファイルは除去する。
異常終了した構成は「プロジェクト → 終了していないセッションを復旧」から選ぶ。
実行中のプロセスはOSロックで除外し、PIDだけで判定しない。
復旧内容は未保存の新しいプロジェクトとして開き、元プロジェクトへ自動で関連付けない。

構成・表示設定に加え、各子の選択・縦横のスクロール・戻る／進む履歴を復旧する。
履歴は200箇所、選択は10万項目まで。表示位置は項目名を優先して復元するため、
以前の位置より前にファイルが増減しても同じ項目を表示できる。
選択・スクロールの変更だけでは、プロジェクトを「未保存」にしない。
通常の戻る／進む操作でも、最近20フォルダの選択と表示位置をプロセス内で保持する。
この20フォルダのキャッシュ全体は復旧ファイルには保存しない。

復旧スナップショットの上限は32親ウィンドウ・合計8 MiB。
選択・表示位置・履歴は専用の個人用ファイル（所有者のみ読み書き可能）へ保存し、
`.mexplore`には含めない。旧版の構成だけを含む復旧情報も読み込める。
実行中のファイル操作を自動再開することはない。保持データは
[中断したファイル操作](file-operations.md)から確認する。
保存失敗時は通知を表示する。直近約1秒の変更は異常終了のタイミングによって失われる。

## JSONのフィールド

| フィールド | 内容 |
| --- | --- |
| `schemaVersion` | `1`。未知の形式では読込みを拒否 |
| `projectID`, `revision` | UUID。保存ごとにrevisionを更新、別名保存でprojectIDも更新 |
| `name` | 1〜255文字。最初の保存ではファイル名を使用 |
| `windowFrame` | 親の位置・サイズ。復元時に利用できるモニター内へ補正 |
| `panes` | 子の追加順。ID、フォルダ参照、通常枠、表示状態、閲覧設定 |
| `zOrder`, `activePaneID` | 背面→前面のID列とアクティブな子 |
| `folder.url`, `folder.bookmark` | ローカルfile URLと任意のBase64 bookmark |
| `normalFrame` | 左上原点、親キャンバスに対する0〜1の比率 |
| `presentation` | `normal` / `minimized` / `maximized` |
| `settings.columns` | `name`, `modified`, `kind`, `size`の順序と幅 |
| `settings.sortColumn`, `ascending` | フォルダ先頭を維持した列ソート |
| `settings.showHidden`, `filter` | 隠し項目と現在のフォルダ内の名前フィルター |
| `settings.treeWidth`, `expandedDirectories`, `favorites` | ツリー幅・展開URL・お気に入り |

読込み・書込みで8 MiB、64子画面、bookmarkは子ごとに128 KiBを上限とする。
列幅は60〜2400 pt、ツリー幅は100〜500 pt、フィルター1024文字、展開256箇所、
お気に入り32箇所。重複ID、不正な重なり順、最小化した子のアクティブ指定、
複数の最大化、非有限・範囲外の座標、非file URLを拒否する。

通常ファイルをサイズ上限付きで読み、一時ファイルへの書込み・flush後に同じディレクトリ内で
原子的に置換する。失敗した一時ファイルは破棄し、元ファイルを保全する。
新しい保存先の確保には排他的なrenameを使う。

ファイルには個人のパスが含まれる。公開するサンプルには架空の参照先を使い、bookmarkや
実際の復旧ファイルを含めない。シェルコマンド・自動実行・読込み時のファイル操作は形式に持たせない。
